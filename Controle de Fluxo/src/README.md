# 🔄 Flow Control | Controle de Fluxo

🇧🇷 Um projeto desenvolvido em **Java** para praticar e demonstrar estruturas de **controle de fluxo**, através de dois sistemas simples:

🇺🇸 A **Java project** developed to practice and demonstrate **flow control structures** through two simple systems:

* 🏦 **Caixa Eletrônico | ATM Simulation**
* 🎓 **Resultado Escolar | School Result Evaluation**

---

## 🚀 Funcionalidades | Features

### 🏦 Caixa Eletrônico | ATM Simulation

🇧🇷 O sistema simula operações básicas de um caixa eletrônico:

🇺🇸 The system simulates basic ATM operations:

* 💰 **Depositar dinheiro | Deposit money**
* 💸 **Sacar dinheiro com validação de saldo | Withdraw money with balance validation**
* 💳 **Consultar saldo | Check balance**

---

### 🎓 Resultado Escolar | School Result Evaluation

🇧🇷 O sistema realiza uma avaliação simples do desempenho do aluno:

🇺🇸 The system performs a simple evaluation of the student's performance:

* 📝 **Inserir notas | Enter grades**
* 📊 **Calcular média | Calculate average**
* ✅ **Verificar aprovação | Determine pass status**
* ❌ **Verificar reprovação | Determine fail status**

---
