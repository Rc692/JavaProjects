## ➕ Operadores | Operators

🇧🇷 A classe `Operadores.java` apresenta exemplos de operadores utilizados para realizar operações e comparações.

🇺🇸 The `Operadores.java` class provides examples of operators used to perform operations and comparisons.

### Operadores Aritméticos | Arithmetic Operators

```text
+   Adição | Addition
-   Subtração | Subtraction
*   Multiplicação | Multiplication
/   Divisão | Division
%   Resto | Modulus
```

### Operadores Relacionais | Relational Operators

```text
==   Igual | Equal
!=   Diferente | Not equal

<    Menor | Less than

```
